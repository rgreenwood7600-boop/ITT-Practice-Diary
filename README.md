# ITT Practice Diary

Monthly practice diary for Initial Trade Training at the Royal Military School of Music, Portsmouth.

Each trainee has one diary. Each month has a comment from the instrumental professor, the academic bandmaster, the section commander, the senior instructor, and the trainee. Trainees register with a username. Staff share one username, `ITTStaff`, and can open every diary.

The page is static and is published with GitHub Pages. Supabase stores the accounts and the diaries. See [SETUP.md](SETUP.md) for the SQL script, the auth settings, and how to create the shared staff login.

There is no analytics, and the diary does not collect a service number.
